2. Dashboard Overview

Four summary cards: Total Students, Submitted, Class Average, Not Submitted.

Four tabs: Scoreboard, Error Analysis, Student Details, Manage Users.

3. Scoreboard

Ranked table of submitted students. 🥇🥈🥉 for top 3.

4. Error Analysis

Questions ranked by error rate. Green ≤25%, Orange 26-50%, Red >50%.

5. Student Details & Score Override

Select a student to view answers. Use Mark Correct / Mark Wrong to override auto-grading. Total recalculates automatically.

6. Manage Users

Add students, reset passwords (🔑), reset submissions (🔄), delete accounts (🗑️).

Reset and Delete are permanent.

7. Messages

Click envelope → select student → type message → send. Students can only message the teacher.

8. Student Self-Registration

Students click "Create New Account" on login page. All accounts appear in Manage Users.
